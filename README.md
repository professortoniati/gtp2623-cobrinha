# 🐍 Neon Snake — Classic Arcade Remixed

Um jogo da cobrinha com uma identidade visual moderna, inspirado nos clássicos jogos Arcade. Desenvolvido com **HTML5, CSS3 e JavaScript puro (Vanilla JavaScript)**, o projeto combina nostalgia, tecnologia e uma experiência de jogo responsiva.

🎮 **Colete energia, aumente sua pontuação e supere seu próprio recorde!**

---

## 🚀 Sobre o Projeto

O **Neon Snake** é uma versão moderna do tradicional Snake Game, com interface futurista, efeitos visuais neon e mecânicas clássicas de movimentação e pontuação.

O objetivo é controlar a cobrinha pelo tabuleiro, coletar os alimentos, aumentar seu tamanho e conquistar a maior pontuação possível, evitando colisões com as paredes ou com o próprio corpo.

O projeto foi desenvolvido utilizando tecnologias nativas da Web, sem dependência de frameworks ou bibliotecas externas.

## ✨ Funcionalidades

- 🐍 **Gameplay clássico:** movimentação da cobrinha em um tabuleiro de 24 × 24 células.
- ⚡ **Pontuação dinâmica:** cada alimento coletado adiciona 10 pontos.
- 🏆 **Sistema de recordes:** armazena a melhor pontuação utilizando LocalStorage.
- 🚀 **Dificuldade progressiva:** a velocidade aumenta gradualmente conforme a pontuação.
- ⏸️ **Sistema de pausa:** permite interromper e continuar a partida.
- 🔄 **Reiniciar partida:** possibilidade de iniciar um novo jogo a qualquer momento.
- 💥 **Game Over:** identificação de colisões com paredes ou com o próprio corpo.
- 📱 **Controles mobile:** botões direcionais e movimentação por gestos (swipe).
- ⌨️ **Controles por teclado:** suporte às setas direcionais e teclas WASD.
- 🎨 **Interface neon:** efeitos de brilho, gradientes, sombras e elementos visuais futuristas.
- 📐 **Layout responsivo:** adaptação para smartphones, tablets e desktops.

## 🛠️ Tecnologias Utilizadas

| Tecnologia | Aplicação no projeto |
|---|---|
| HTML5 | Estrutura e organização da interface |
| CSS3 | Estilização, layout responsivo, animações e efeitos visuais |

## 🎮 Como Jogar

O funcionamento é simples:

1. Clique em **INICIAR JOGO**.
2. Utilize os controles para movimentar a cobrinha.
3. Colete os alimentos para aumentar sua pontuação.
4. Evite bater nas paredes ou no próprio corpo.
5. Tente superar seu recorde!

### ⌨️ Controles

| Ação | Teclas |
|---|---|
| Mover para cima | ⬆️ ou W |
| Mover para baixo | ⬇️ ou S |
| Mover para esquerda | ⬅️ ou A |
| Mover para direita | ➡️ ou D |
| Pausar / Continuar | Espaço |
| Iniciar partida | Enter |

📱 **Em dispositivos móveis:** utilize os botões direcionais ou deslize o dedo sobre o tabuleiro para controlar a cobrinha.
